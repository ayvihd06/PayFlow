# PayFlow

> Manage People. Simplify Payroll.

PayFlow is a modern SaaS-based Human Resource and Payroll Management System built with NestJS, Next.js, PostgreSQL, Prisma, and Docker.

---

## Features

- Authentication & Authorization
- Employee Management
- Department & Designation Management
- Attendance Tracking
- Leave Management
- Payroll Generation
- Payslip Management
- Dashboard & Analytics
- Reports

---

## Tech Stack

### Backend

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Infrastructure

- Docker
- Docker Compose
